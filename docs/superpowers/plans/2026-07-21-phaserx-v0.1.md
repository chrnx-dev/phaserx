# PhaserX v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir PhaserX v0.1 — una capa de decoradores stage-3 y ECS sobre Phaser 4 — más un juego demo que valide la ergonomía de la API.

**Architecture:** Los componentes son stores SoA de TypedArrays construidos por `component(class {...})` con field decorators de tipo. bitECS 0.4 aporta entidades, queries y observers; PhaserX aporta la capa tipada. Un bridge con orden de sync fijo por frame mantiene coherentes el ECS y los GameObjects de Phaser.

**Tech Stack:** `phaser@4.2.1`, `bitecs@0.4.0`, `typescript@5.9`, `vite@7`, `vitest@4`.

## Global Constraints

- **Decoradores stage-3 únicamente.** `experimentalDecorators: false` en tsconfig. Nunca importar ni depender de `reflect-metadata`.
- **Cero dependencias de runtime** salvo `bitecs`. `phaser` es peer dependency.
- **TypeScript strict.** `"strict": true`. Ningún `any` en la API pública; en implementación interna se permite pero debe quedar encapsulado.
- **Los decoradores no pueden cambiar tipos.** Verificado con `tsc --strict`: TypeScript no ensancha el tipo de una clase con el valor devuelto por su class decorator, ni con una intersección. Consecuencia aplicada en todo el plan: cuando una API necesita aportar miembros tipados, se usa una **función** (`component()`) o una **clase base** (`GameScene`), nunca un class decorator. Los class decorators se usan solo para registrar metadata (`@Scene`, `@System`).
- **Orden de sync por frame, inviolable:** systems de lógica → PreSync (ECS→GameObject) → update de Phaser (física, tweens) → PostSync (GameObject→ECS). Phaser es autoridad de transform después de física; el ECS es autoridad de decisión antes.
- **El manifest de assets nunca carga.** Solo describe. `@Asset` es el único disparador de carga.
- **Capacidad fija.** Los TypedArrays se asignan con capacidad fija (`DEFAULT_CAPACITY = 10_000`), configurable por componente. Exceder el rango es un error documentado, no un crecimiento silencioso.
- Todo test corre headless con Vitest. Solo el demo instancia Phaser real.

```ts
/** Una columna de datos numericos indexada por entity id. */
export type Column = { [i: number]: number; readonly length: number }

/** Descriptor de columna recolectado por los field decorators. */
export type ColumnSpec = { name: string; make: (capacity: number) => unknown }

/**
 * Buffer module-level de columnas pendientes.
 *
 * Los field decorators se aplican al definirse la clase, antes de que
 * `component()` reciba la clase ya construida. Cada decorador empuja su
 * descriptor aca y `component()` drena el buffer inmediatamente despues.
 * El orden lo garantiza la especificacion de decoradores: todos los field
 * decorators de una clase corren durante su definicion.
 */
let pending: ColumnSpec[] = []

/** Vacia el buffer y devuelve lo acumulado. Solo lo usa `component()`. */
export function drainColumns(): ColumnSpec[] {
  const cols = pending
  pending = []
  return cols
}

/**
 * Rechaza un campo invalido descartando el batch en curso.
 *
 * Si un field decorator lanza, la clase nunca termina de definirse y por lo
 * tanto nunca llega a `component()`, asi que nadie drena el buffer. Sin este
 * descarte las columnas ya acumuladas de esa clase se filtrarian al proximo
 * componente que se defina, que puede ser uno totalmente ajeno.
 */
function reject(who: string, name: string | symbol, why: string): never {
  pending = []
  throw new Error(`${who}: '${String(name)}' ${why}`)
}

function numericColumn(make: (capacity: number) => unknown) {
  return function <T>(_value: undefined, ctx: ClassFieldDecoratorContext<T, number>) {
    if (ctx.static) reject('@column', ctx.name, 'no puede ser static')
    if (ctx.private) reject('@column', ctx.name, 'no puede ser privado')
    pending.push({ name: String(ctx.name), make })
  }
}

export const f32 = numericColumn(n => new Float32Array(n))
export const f64 = numericColumn(n => new Float64Array(n))
export const i8 = numericColumn(n => new Int8Array(n))
export const i16 = numericColumn(n => new Int16Array(n))
export const i32 = numericColumn(n => new Int32Array(n))
export const u8 = numericColumn(n => new Uint8Array(n))
export const u16 = numericColumn(n => new Uint16Array(n))
export const u32 = numericColumn(n => new Uint32Array(n))
```

- [ ] **Step 4: Escribir `src/core/component.ts`**

```ts
import { type Column, drainColumns } from './column'

export const DEFAULT_CAPACITY = 10_000

/** Mapea la forma de instancia de la clase a su store de columnas. */
export type SoA<T> = { [K in keyof T]: T[K] extends number ? Column : T[K][] }

/**
 * Materializa una clase de declaracion en un store SoA.
 *
 * Es una funcion y no un class decorator porque TypeScript no ensancha el
 * tipo de una clase con el valor devuelto por su decorador: `@Component`
 * daria `Property 'x' does not exist on type 'typeof Position'` en cada
 * acceso. Verificado con tsc --strict.
 */
export function component<C extends new () => unknown>(
  cls: C,
  capacity: number = DEFAULT_CAPACITY,
): SoA<InstanceType<C>> {
  void cls // la clase solo aporta su tipo; los datos vienen del buffer
  const store: Record<string, unknown> = {}
  for (const col of drainColumns()) store[col.name] = col.make(capacity)
  return store as SoA<InstanceType<C>>
}
```

```ts
import {
  addComponent,
  addEntity,
  createWorld,
  hasComponent,
  observe,
  onAdd as bitOnAdd,
  onRemove as bitOnRemove,
  query,
  removeEntity,
  type World as BitWorld,
} from 'bitecs'
import type { Column } from './column'

export type Entity = number

/** Valores admitidos al inicializar un componente. */
export type Values<S> = {
  [K in keyof S]?: S[K] extends Column ? number : S[K] extends Array<infer U> ? U : never
}

export type Setter = { component: object; values: Record<string, unknown> }

/** Empareja un componente con los valores iniciales de sus columnas. */
export function set<S extends object>(component: S, values: Values<S>): Setter {
  return { component, values: values as Record<string, unknown> }
}

function isSetter(part: object | Setter): part is Setter {
  return 'component' in part && 'values' in part
}

export class World {
  readonly raw: BitWorld

  constructor() {
    this.raw = createWorld()
  }

  /**
   * Crea una entidad con los componentes indicados.
   *
   * El orden importa: los componentes se aplican de izquierda a derecha, asi
   * que un componente cuyo observer lea datos de otro (por ejemplo Sprite
   * leyendo Position) debe ir despues de ese otro.
   */
  spawn(...parts: (object | Setter)[]): Entity {
    const eid = addEntity(this.raw)
    for (const part of parts) {
      if (isSetter(part)) {
        // Los valores se escriben ANTES de addComponent a proposito: los
        // observers onAdd se disparan dentro de addComponent y deben ver el
        // componente ya inicializado. Escribir columnas no requiere que el
        // componente este agregado; son arrays planos indexados por eid.
        const store = part.component as Record<string, { [i: number]: unknown }>
        for (const key of Object.keys(part.values)) {
          const column = store[key]
          if (column === undefined) {
            throw new Error(`spawn: el componente no tiene la columna '${key}'`)
          }
          column[eid] = part.values[key]
        }
        addComponent(this.raw, eid, part.component)
      } else {
        addComponent(this.raw, eid, part)
      }
    }
    return eid
  }

  destroy(entity: Entity): void {
    removeEntity(this.raw, entity)
  }

  has(entity: Entity, component: object): boolean {
    return hasComponent(this.raw, entity, component)
  }

  query(...components: object[]): readonly Entity[] {
    return query(this.raw, components)
  }

  onAdd(component: object, callback: (entity: Entity) => void): void {
    observe(this.raw, bitOnAdd(component), (eid: number) => {
      callback(eid)
    })
  }

  onRemove(component: object, callback: (entity: Entity) => void): void {
    observe(this.raw, bitOnRemove(component), (eid: number) => {
      callback(eid)
    })
  }
}
```

```ts
import type { Entity, World } from './world'

/** Clave donde la escena deposita el world de cada system. */
export const WORLD = Symbol('phaserx.world')

export type QueryResult = Iterable<Entity> & { readonly length: number }

export interface SystemInstance {
  update?(dt: number): void
}

/** Marca una clase como system. Registrar es todo lo que hace. */
const systems = new WeakSet<Function>()

export function System() {
  return function (value: Function, _ctx: ClassDecoratorContext): void {
    systems.add(value)
  }
}

export function isSystem(cls: Function): boolean {
  return systems.has(cls)
}

/** Inyecta el world en un system ya construido. */
export function bindWorld(system: object, world: World): void {
  ;(system as Record<symbol, World>)[WORLD] = world
}

class LazyQuery implements QueryResult {
  constructor(
    private readonly owner: object,
    private readonly components: object[],
  ) {}

  private resolve(): readonly Entity[] {
    const world = (this.owner as Record<symbol, World | undefined>)[WORLD]
    if (world === undefined) {
      throw new Error('@Query: system sin world. Falta bindWorld() o registrarlo en una escena.')
    }
    return world.query(...this.components)
  }

  [Symbol.iterator](): Iterator<Entity> {
    return this.resolve()[Symbol.iterator]()
  }

  get length(): number {
    return this.resolve().length
  }
}

/**
 * Expone las entidades que tienen todos los componentes indicados.
 *
 * Resuelve en cada acceso, no en construccion: el world se inyecta despues
 * de construir el system y las entidades cambian cada frame.
 */
export function Query(...components: object[]) {
  return function <T extends object>(
    _value: undefined,
    _ctx: ClassFieldDecoratorContext<T, QueryResult>,
  ) {
    return function (this: T): QueryResult {
      return new LazyQuery(this, components)
    }
  }
}
```

```ts
/**
 * Service locator minimo.
 *
 * No hay inyeccion por tipo inferido a proposito: eso exigiria decoradores
 * legacy y reflect-metadata, que solo funcionan con clases (no interfaces),
 * se rompen con imports circulares y obligan a un plugin de bundler. Un juego
 * necesita un punado de servicios; el token explicito los cubre sin runtime extra.
 */
export class Token<T> {
  declare private readonly __type?: T // hace el token invariante en T
  constructor(readonly name: string) {}
}

const providers = new Map<Token<unknown>, unknown>()

export function provide<T>(token: Token<T>, value: T): void {
  providers.set(token as Token<unknown>, value)
}

export function resolve<T>(token: Token<T>): T {
  if (!providers.has(token as Token<unknown>)) {
    throw new Error(`DI: no hay provider para el token '${token.name}'`)
  }
  return providers.get(token as Token<unknown>) as T
}

export function clearProviders(): void {
  providers.clear()
}

/** Resuelve el token al construirse la instancia. */
export function Inject<T>(token: Token<T>) {
  return function <C extends object>(
    _value: undefined,
    _ctx: ClassFieldDecoratorContext<C, T>,
  ) {
    return function (): T {
      return resolve(token)
    }
  }
}
```

```ts
export type ImageSpec = { type: 'image'; url: string }
export type SpritesheetSpec = {
  type: 'spritesheet'
  url: string
  frameWidth: number
  frameHeight?: number
}
export type AudioSpec = { type: 'audio'; url: string }
export type AssetSpec = ImageSpec | SpritesheetSpec | AudioSpec

/** Spec ya registrado en un manifest, con su key resuelta. */
export type KeyedSpec<S extends AssetSpec = AssetSpec> = S & { key: string }

/** Recurso de Phaser que corresponde a cada tipo de spec. */
export type LoadedAsset<S extends AssetSpec> = S extends AudioSpec
  ? Phaser.Sound.BaseSound
  : Phaser.Textures.Texture

type Manifested<T extends Record<string, AssetSpec>> = {
  [K in keyof T]: T[K] & { key: K & string }
}

/**
 * Declara el manifest de assets. Solo describe: no carga nada.
 * La key de cada asset se toma del nombre del campo.
 */
export function defineAssets<T extends Record<string, AssetSpec>>(manifest: T): Manifested<T> {
  for (const key of Object.keys(manifest)) {
    ;(manifest[key] as KeyedSpec).key = key
  }
  return manifest as Manifested<T>
}

export type AssetBinding = { property: string; spec: KeyedSpec }

let pending: AssetBinding[] = []

/** Vacia el buffer de bindings. Lo consume @Scene. */
export function drainAssets(): AssetBinding[] {
  const bindings = pending
  pending = []
  return bindings
}

/**
 * Declara que la escena depende de un asset.
 *
 * Es el unico disparador de carga del framework: @Scene junta estos bindings
 * y los emite al loader en preload, y asigna el recurso a la propiedad
 * despues de que termina la carga.
 */
export function Asset<S extends AssetSpec>(spec: S) {
  return function <T extends object>(
    _value: undefined,
    ctx: ClassFieldDecoratorContext<T, LoadedAsset<S>>,
  ) {
    const keyed = spec as KeyedSpec<S>
    if (keyed.key === undefined) {
      throw new Error('@Asset: el spec no viene de defineAssets(), le falta la key')
    }
    pending.push({ property: String(ctx.name), spec: keyed })
  }
}
```

```ts
import Phaser from 'phaser'
import { type AssetBinding, drainAssets } from '../assets/index'
import { bindWorld, type SystemInstance } from '../core/system'
import { World } from '../core/world'

export type SceneConfig = {
  key: string
  systems?: Array<new () => SystemInstance>
}

export type SceneMeta = {
  key: string
  systems: Array<new () => SystemInstance>
  assets: AssetBinding[]
}

const metas = new WeakMap<Function, SceneMeta>()

/**
 * Registra una escena: su key, sus systems y los @Asset que declaro.
 *
 * Solo guarda metadata. Los miembros tipados (this.world, this.add, ...) los
 * aporta la clase base GameScene, porque un class decorator no puede agregar
 * miembros al tipo de la clase decorada.
 */
export function Scene(config: SceneConfig) {
  return function (value: Function, _ctx: ClassDecoratorContext): void {
    metas.set(value, {
      key: config.key,
      systems: config.systems ?? [],
      assets: drainAssets(),
    })
  }
}

export function getSceneMeta(cls: Function): SceneMeta | undefined {
  return metas.get(cls)
}

/** Corre los systems en orden de declaracion. `deltaMs` viene de Phaser. */
export function runSystems(systems: object[], world: World, deltaMs: number): void {
  const dt = deltaMs / 1000
  for (const system of systems) {
    bindWorld(system, world)
    const update = (system as SystemInstance).update
    if (typeof update === 'function') update.call(system, dt)
  }
}

/**
 * Clase base de toda escena de PhaserX.
 *
 * Aporta el world, corre los systems y resuelve los @Asset. Las subclases
 * usan onCreate() en lugar de create() para no tener que llamar a super.
 */
export abstract class GameScene extends Phaser.Scene {
  readonly world = new World()
  protected systems: SystemInstance[] = []

  constructor() {
    // new.target es la subclase concreta y esta disponible antes de super(),
    // asi que la key llega al constructor de Phaser por la via normal en vez
    // de mutar sys.settings despues.
    const meta = getSceneMeta(new.target)
    if (meta === undefined) {
      throw new Error(`${new.target.name}: falta el decorador @Scene`)
    }
    super(meta.key)
  }

  private get meta(): SceneMeta {
    return getSceneMeta(this.constructor)!
  }

  preload(): void {
    for (const { spec } of this.meta.assets) {
      switch (spec.type) {
        case 'image':
          this.load.image(spec.key, spec.url)
          break
        case 'spritesheet':
          this.load.spritesheet(spec.key, spec.url, {
            frameWidth: spec.frameWidth,
            frameHeight: spec.frameHeight ?? spec.frameWidth,
          })
          break
        case 'audio':
          this.load.audio(spec.key, spec.url)
          break
      }
    }
  }

  create(): void {
    for (const { property, spec } of this.meta.assets) {
      const target = this as unknown as Record<string, unknown>
      target[property] =
        spec.type === 'audio' ? this.sound.add(spec.key) : this.textures.get(spec.key)
    }
    this.systems = this.meta.systems.map(S => new S())
    this.onCreate?.()
  }

  update(_time: number, delta: number): void {
    runSystems(this.systems, this.world, delta)
    this.onUpdate?.(delta / 1000)
  }

  /** Hook de la subclase. Corre despues de resolver assets y construir systems. */
  protected onCreate?(): void
  /** Hook opcional de la subclase, con el delta ya en segundos. */
  protected onUpdate?(dt: number): void
}
```

```ts
import { f32, ref } from '../core/column'
import { component } from '../core/component'
import { set, type Setter, type World } from '../core/world'

export const Position = component(class { @f32 x = 0; @f32 y = 0 })
export const Velocity = component(class { @f32 x = 0; @f32 y = 0 })

/** Lo minimo que el bridge necesita de un GameObject. Facilita testear sin canvas. */
export interface SpriteLike {
  x: number
  y: number
  destroy(): void
  body?: { velocity: { x: number; y: number } } | null
}

export const Sprite = component(
  class {
    @ref key!: string
    @ref go!: SpriteLike
  },
)

export type SpriteFactory = (key: string, x: number, y: number) => SpriteLike

/**
 * Conecta el ciclo de vida de los GameObjects al del world.
 *
 * Debe llamarse una vez por world, antes del primer spawn con sprite().
 */
export function attachSprites(world: World, factory: SpriteFactory): void {
  // El bridge se auto-registra en los hooks de frame del world. GameScene los
  // corre en PRE_UPDATE y POST_UPDATE, que es donde caen a ambos lados del
  // step de fisica de Phaser. Asi el usuario no tiene que acordarse del orden.
  world.onPreSync(() => preSync(world))
  world.onPostSync(() => postSync(world))

  world.onAdd(Sprite, eid => {
    // World.spawn escribe las columnas antes de addComponent, asi que 'key'
    // ya esta puesta cuando corre este observer.
    const key = Sprite.key[eid]
    if (key === undefined) {
      throw new Error('Sprite: falta la textura. Usar el helper sprite().')
    }
    Sprite.go[eid] = factory(key, Position.x[eid], Position.y[eid])
  })

  world.onRemove(Sprite, eid => {
    const go = Sprite.go[eid]
    if (go !== undefined) go.destroy()
    // Liberar las referencias: sin esto el array retiene el GameObject y la
    // entidad reciclada heredaria el sprite del ocupante anterior.
    delete Sprite.go[eid]
    delete Sprite.key[eid]
  })
}

/**
 * Crea el GameObject de la entidad a partir de un asset.
 *
 * Debe ir despues de Position en la lista de spawn: el observer lee la
 * posicion de la entidad al construir el GameObject.
 */
export function sprite(spec: { key: string }): Setter {
  return set(Sprite, { key: spec.key })
}

/** ECS -> GameObject. Lo corre GameScene en PRE_UPDATE, antes de la fisica. */
export function preSync(world: World): void {
  for (const eid of world.query(Sprite, Velocity)) {
    const go = Sprite.go[eid]
    if (go?.body) {
      go.body.velocity.x = Velocity.x[eid]
      go.body.velocity.y = Velocity.y[eid]
    }
  }
}

/** GameObject -> ECS. Lo corre GameScene en POST_UPDATE, despues de la fisica. */
export function postSync(world: World): void {
  for (const eid of world.query(Sprite, Position)) {
    const go = Sprite.go[eid]
    if (go !== undefined) {
      Position.x[eid] = go.x
      Position.y[eid] = go.y
    }
  }
}
```

```ts
import { Position, Query, type QueryResult, System, Velocity } from '../src/index'
import { Enemy, Health, Player } from './components'

const SPEED = 200

@System()
export class PlayerInputSystem {
  @Query(Player, Velocity) players!: QueryResult

  constructor(private readonly keys: { left: boolean; right: boolean; up: boolean; down: boolean }) {}

  update(): void {
    for (const e of this.players) {
      Velocity.x[e] = (this.keys.right ? SPEED : 0) - (this.keys.left ? SPEED : 0)
      Velocity.y[e] = (this.keys.down ? SPEED : 0) - (this.keys.up ? SPEED : 0)
    }
  }
}

@System()
export class ChaseSystem {
  @Query(Enemy, Position, Velocity) enemies!: QueryResult
  @Query(Player, Position) players!: QueryResult

  update(): void {
    const target = [...this.players][0]
    if (target === undefined) return
    for (const e of this.enemies) {
      const dx = Position.x[target] - Position.x[e]
      const dy = Position.y[target] - Position.y[e]
      const dist = Math.hypot(dx, dy) || 1
      const speed = Enemy.chaseSpeed[e]
      Velocity.x[e] = (dx / dist) * speed
      Velocity.y[e] = (dy / dist) * speed
    }
  }
}

@System()
export class DeathSystem {
  @Query(Health) mortales!: QueryResult

  constructor(private readonly onDeath: (entity: number) => void) {}

  update(): void {
    for (const e of this.mortales) {
      if (Health.hp[e] <= 0) this.onDeath(e)
    }
  }
}
```

Es el caso que justifica que `runSystems` acepte instancias y no solo constructores. Si al escribir la escena resulta incómodo, ese es exactamente el tipo de hallazgo que el demo existe para producir: anotarlo y ajustar la API.

```ts
import Phaser from 'phaser'
import { attachSprites, GameScene, Position, Scene, set, sprite, Velocity } from '../src/index'
import { A } from './assets'
import { Enemy, Health, Player } from './components'
import { ChaseSystem, DeathSystem, PlayerInputSystem } from './systems'

const keys = { left: false, right: false, up: false, down: false }

@Scene({ key: 'juego' })
export class JuegoScene extends GameScene {
  protected onCreate(): void {
    attachSprites(this.world, (key, x, y) => this.physics.add.sprite(x, y, key))

    this.systems = [
      new PlayerInputSystem(keys),
      new ChaseSystem(),
      new DeathSystem(e => this.world.destroy(e)),
    ]

    this.world.spawn(
      set(Position, { x: 400, y: 300 }),
      set(Velocity, { x: 0, y: 0 }),
      Player,
      set(Health, { hp: 100 }),
      sprite(A.player),
    )

    for (let i = 0; i < 5; i++) {
      this.world.spawn(
        set(Position, { x: 100 + i * 120, y: 80 }),
        set(Velocity, { x: 0, y: 0 }),
        set(Enemy, { chaseSpeed: 60 }),
        set(Health, { hp: 10 }),
        sprite(A.enemy),
      )
    }

    const cursors = this.input.keyboard!.createCursorKeys()
    this.events.on(Phaser.Scenes.Events.PRE_UPDATE, () => {
      keys.left = cursors.left.isDown
      keys.right = cursors.right.isDown
      keys.up = cursors.up.isDown
      keys.down = cursors.down.isDown
    })
  }
}
```
